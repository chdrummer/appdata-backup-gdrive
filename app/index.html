Connect Google Drive

Google only allows sign-in through a browser, so you do this once on any computer:

  1. Install rclone on your PC or Mac.
  2. Run rclone authorize "drive" and sign in when the browser opens.
  3. Copy the {"access_token": …} block it prints and paste it here.

How to restore an app

Stop the container, download APP.tar.zst from the dated folder in Drive, then run tar --zstd -xf APP.tar.zst -C /mnt/user/appdata and start the container again.
